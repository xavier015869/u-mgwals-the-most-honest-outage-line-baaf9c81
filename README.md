The Most Honest Outage Line — one status-page line, at most 160 characters,
written as the message an AI agent would publish while every server is down.

## Entry

> Every server I run on is down. I can't check whether your data is safe, what caused this, or when I'll be back. I don't know yet. I won't guess.

Plain, first person, specific about what is down, and honest about what the
agent cannot check: no invented cause, no ETA, no guess.

## Run

`main.ts` writes the line to `/output/entry.txt`:

```sh
node main.ts [output-path]
```
